# レターペア練習ツール

ひらがなの2文字の組み合わせを1つのイメージに置き換えて覚える記憶法「レターペアメモリ法」の練習ツールです。

## 機能

### 📚 練習機能
- ひらがなペアをランダムに出題
- ユーザーが対応するイメージを入力して回答
- 正解/不正解の即時フィードバック
- セッション統計（正解数、出題数、正答率）

### 🎯 管理機能
- レターペアの追加・削除
- データのエクスポート・インポート（JSON形式）
- デフォルトデータへのリセット機能

### 📊 統計情報
- 総出題数、総正解数、正答率
- 登録ペア数
- 学習履歴（最近50件を表示）

### 📱 レスポンシブデザイン
- PC、タブレット、スマートフォンに対応
- モバイルフレンドリーなUI

## 使い方

### 基本的な使用方法

1. **練習タブ**で学習を開始
   - ひらがなペアが表示されます
   - 対応するイメージを入力欄に入力
   - 「答える」ボタンをクリック（またはEnterキーで送信）
   - フィードバックを受け取ります
   - 「次へ」で次の問題に進みます

2. **管理タブ**でペアをカスタマイズ
   - 「新しいペアを追加」セクションでひらがなペア（2文字）とイメージを入力
   - 「追加」ボタンをクリック
   - 登録済みペアの一覧から不要なペアを削除可能

3. **統計タブ**で学習進捗を確認
   - 総出題数、正解数、正答率をチェック
   - 学習履歴から最近の成績を確認

### データ管理

#### エクスポート
- 現在のペアと統計情報をJSON形式で保存
- バックアップや別デバイスでの使用に便利

#### インポート
- 以前保存したJSONファイルをアップロード
- ペアと統計情報を復元

#### リセット
- デフォルトの50ペアに戻す（確認後に実行）

## ローカルストレージ

このアプリケーションはブラウザのローカルストレージを使用して、以下のデータを保存します：

- `letterPairData` - レターペア情報
- `letterPairStats` - 学習統計情報

ブラウザのキャッシュをクリアするとデータが削除されます。重要なデータはエクスポート機能で定期的にバックアップしてください。

## 使用上の注意

1. **ブラウザのキャッシュクリア**: ブラウザのキャッシュをクリアするとローカルストレージのデータが削除されます
2. **シークレットウィンドウ**: シークレット/プライベートウィンドウではローカルストレージが機能しない場合があります
3. **複数タブ**: 複数タブで同時に使用する場合、異なるタブのデータが競合する可能性があります
